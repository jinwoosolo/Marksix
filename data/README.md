# Data

`data/marksix.csv` is created automatically on first launch by downloading the legacy public dataset from:

`https://raw.githubusercontent.com/jinwoosolo/Marksix-analyzer/main/marksix.csv`

Expected columns:

`date,n1,n2,n3,n4,n5,n6,extra,...`

The V2 loader validates number ranges, six distinct main numbers, date ordering, duplicates and Extra-number separation.
